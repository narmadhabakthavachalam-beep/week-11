# Week 11 - Vector Embeddings with ChromaDB

## Technologies Used
- Python
- Sentence Transformers
- ChromaDB
- NumPy
- Pandas

## Embedding Model
all-MiniLM-L6-v2

## Dataset
10 Technology-related text documents.

## Implementation
1. Loaded 10 text documents.
2. Generated vector embeddings.
3. Saved embeddings using NumPy.
4. Stored documents in ChromaDB.
5. Performed semantic search.
6. Retrieved Top-5 results for 10 queries.
7. Compared semantic search with keyword search.

## Output Files
- embeddings.npy
- retrieved_results.csv
- comparison_results.csv

## Conclusion
Vector embeddings and ChromaDB were used to perform semantic search and retrieve relevant documents.
